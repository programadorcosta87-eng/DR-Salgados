# DR Salgados — Cardápio Digital

Cardápio digital completo para lanchonete, com sistema de pedidos em tempo real e painel administrativo.

🔗 Acesse o projeto: https://dr-salgados.netlify.app

---

## 📋 Sobre o projeto

O **DR Salgados** foi desenvolvido para modernizar o atendimento de lanchonetes, hamburguerias, pastelarias e outros estabelecimentos que trabalham com pedidos presenciais, retirada ou entrega.

A aplicação reúne o cardápio digital, seleção de produtos, carrinho de pedidos e gerenciamento dos pedidos em uma única experiência. O projeto também conta com uma área administrativa para facilitar o gerenciamento do estabelecimento.

A proposta é oferecer uma solução simples para o cliente final e, ao mesmo tempo, disponibilizar recursos que ajudam o estabelecimento a organizar o atendimento e acompanhar os pedidos.

---

## ✨ Funcionalidades

* Cardápio interativo com categorias e busca
* Carrinho de pedidos
* Seleção de mesa + opções de retirada/entrega
* Painel administrativo e de funcionários
* Pedidos sincronizados em tempo real (Firebase)
* Integração com WhatsApp
* Progressive Web App (instalável)
* Interface responsiva para diferentes tamanhos de tela
* Organização dos produtos por categorias
* Fluxo de pedido pensado para reduzir etapas desnecessárias

## 🎯 Objetivo

O projeto foi criado com foco em uma situação real de negócio: permitir que um estabelecimento tenha um sistema próprio de cardápio e pedidos, reduzindo a dependência de processos manuais e tornando o atendimento mais organizado.

Além da interface para o cliente, a aplicação demonstra conceitos importantes de desenvolvimento web, como gerenciamento de estado, integração com banco de dados, sincronização de informações e criação de uma aplicação instalável.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/DR-Salgados.git
```

### 2. Entre na pasta

```bash
cd DR-Salgados
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

Depois, acesse no navegador o endereço local informado pelo Vite.

---

## 📦 Build para produção

Para gerar a versão de produção:

```bash
npm run build
```
